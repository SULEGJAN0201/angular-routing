🔍 Routing Concept: Wildcard Route

This component is shown for all undefined routes using the wildcard path **

In app.routes.ts, this route is configured as:

{{ '{' }} path: '**', component: NotFoundComponent {{ '}' }}

⚠️ The wildcard route must be the LAST route in the configuration!
