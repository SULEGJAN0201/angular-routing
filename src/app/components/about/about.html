ℹ️ About This Application

Angular Routing Learning Application

This application is designed to teach Angular routing concepts from beginner to advanced level.

Purpose

Every component, service, and configuration file includes comprehensive comments explaining the routing concepts being demonstrated.

Technologies Used

  • Angular 18+ with Standalone Components
  • TypeScript for type safety
  • Angular Router with modern features
  • Signals for reactive state management

Routing Features Covered

  • ✅ Basic route configuration
  • ✅ Route parameters and query parameters
  • ✅ Nested/child routes
  • ✅ Route guards (canActivate)
  • ✅ Route resolvers
  • ✅ Lazy loading with loadChildren
  • ✅ Programmatic navigation
  • ✅ RouterLink and RouterLinkActive directives
